# Changelog

All notable changes to the Medical App project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-05-21

### Added
- Initial release of Medical App
- User authentication system (login/registration)
- Admin authentication module
- Multi-language support (English, French, Arabic)
- Assessment management system
- Patient dashboard
- Admin dashboard
- Medical assessment forms with dynamic questions
- Assessment response tracking
- SQLite database integration
- Secure local storage with SharedPreferences
- Video player integration (YouTube & local videos)
- PDF report generation and printing
- User profile management
- Language selection on login screen
- Professional UI with Material Design 3
- Responsive design for multiple screen sizes

### Technical Stack
- Flutter 3.11.0+
- Dart 3.1.0+
- Provider 6.0.0 for state management
- SQLite for local database
- Material Design 3 components

### Security Features
- Secure password hashing (crypto package)
- Encrypted local storage
- Session management
- Input validation and sanitization
